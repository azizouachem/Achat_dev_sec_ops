# Achat DevSecOps Project

This repository contains the source code and DevOps infrastructure for the Achat project.

## 🚀 Overview

The project is a Spring Boot application industrialized with a full DevSecOps pipeline, including:
- **CI/CD**: Jenkins pipeline (`Jenkinsfile`)
- **Infrastructure**: Docker Compose for local development and infrastructure services.
- **Monitoring**: Prometheus & Grafana (configured in infra).
- **Security**: DevSecOps best practices.

## 🛠️ Tech Stack
- **Backend**: Java, Spring Boot, Maven
- **DevOps**: Jenkins, Docker, SonarQube, Nexus
- **Monitoring**: Prometheus, Grafana
